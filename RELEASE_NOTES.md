# ChatVault v0.1.10 — Local backup integrity validation

- После первой успешной пользовательской копии (72 чата на скриншоте) добавлена проверка локально сохранённых данных.
- В разделе **Журнал** появилась кнопка **«Проверить сохранённое»**.
- Для последнего непустого снимка сверяются ревизии, SHA-256, наличие графов сообщений и дубликаты ID. Результат содержит количество исправных и проблемных записей.
- Проверка не обращается к ChatGPT API и не расходует лимиты. Настройки и IndexedDB сохраняются.
- Добавлены 5 регрессионных тестов повреждённого JSON, пропущенных ревизий, повторов, неполных копий и нормального снимка.

**Ограничения:** успешная проверка локальной базы не проверяет скачанный ZIP, вложения и полноту истории ChatGPT. Сам ZIP следует отдельно проверить архиватором и сравнить число папок с `manifest.json`.
