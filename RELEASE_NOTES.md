# ChatVault v0.1.4 — Compact Interface

- Интерфейс стал компактнее: главная, журнал и настройки в отдельных вкладках.
- Главная показывает только статус, 3 показателя, время копий и 2 действия.
- Расписание, календарь, переключатель светлой/тёмной темы и автоскачивание ZIP перенесены в настройки.
- Диагностика подключения и исторические ошибки доступны в журнале.
- Сообщения об ошибках на главном экране сокращены; исходные детали остаются в журнале.
- Текущие настройки и локальные архивы не сбрасываются при обновлении.

**Ограничения:** внутренний API ChatGPT остаётся экспериментальным; вложения и инструкции проектов пока не скачиваются; успешные сборки и тесты не гарантируют реальный экспорт аккаунта.
